## 평가 방법과 주요 결과

별도 모델 평가 없음 (EDA 단계). 노트북 실행 결과:

- 스키마: 440,274행 × 77열 (float64 70, int64 6, str 1).
- NaN 결측치 0건. "결측치 포함 대량 행"이라는 이슈 전제는 실제 NaN이 아니라
  `mapping.json` 기준 무효(해당없음) `inspection_feat` 컬럼을 가리키는 것으로 재해석됨.
- 클래스 불균형(전체 재확인): type0 0.33% / type1 2.74% / type2 1.05% /
  type3 0.84% / type4 1.82% — 기존 `notes.md` 표와 대체로 일치.
- **무효 컬럼 채움값이 inspection_type마다 다름.** type 0/1/4는 무효 셀의
  44~72%가 0이지만, type 2/3는 무효 셀에 0이 전혀 없고 대신 약 0.48~0.60 범위의
  (준)상수 값으로 채워짐 → 값 기반("0이면 무효") 판단은 불가능, `mapping.json`
  기반 명시적 마스킹이 필요.
- 유효 컬럼 중에도 상수열(nunique<=1) 비중이 큼: type0 7/44, type1 28/52,
  type2 45/65, type3 46/65, type4 8/21.
- 70개 `inspection_feat` 전부 [0, 1] 범위 내, 범위 이탈 이상치 없음.
- 완전 중복행 8,752건(1.99%) 존재.
- timestamp는 132일 구간이나 실제 데이터 존재일은 101일(공백 약 31일), 일별
  건수 편차 큼(12~23,046건).
