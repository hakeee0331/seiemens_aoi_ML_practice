## 목적

004 단일 타입별 Walk-forward 모델의 데이터·분할·XGBoost·임계값 규칙을 고정하고, 각 타입의 Train에서 상수 및 완전중복 컬럼만 제거했을 때 미래 일반화가 개선되는지 확인한다.

## 처리 원칙

- 각 Fold·타입의 Train에서만 제거 목록을 학습하고 Calibration/Evaluation에 고정 적용했다.
- 0~70% 최종 Train에서도 다시 목록을 학습해 70~80% Validation에 적용했다.
- 행 중복 제거, 이상치 제거, 준상수 제거, label 기반 선택은 하지 않았다.
- 최종 Train 기준 타입 0~4에서 상수 컬럼은 각각 7/28/45/47/8개, 완전중복 컬럼은 0/2/0/0/2개 제거됐다.
- 모델과 임계값을 Validation에서 고정한 뒤 마지막 20% Test를 진단 목적으로 한 번 평가했다. 이 결과를 이용한 추가 튜닝은 허용하지 않는다.

## 결론

- Walk-forward 평균 FCR은 `+0.81%p` 개선됐지만 PR-AUC는 낮아졌고, Recall 안정성은 변하지 않았다.
- Validation에서는 PR-AUC가 `+0.000358`로 사실상 같았으나 동일 Recall에서 FP가 526개 증가해 FCR이 `-1.20%p` 하락했다.
- 상수·완전중복 제거는 계산량을 줄이는 안전한 정리로는 유효하지만, 현재 증거만으로 성능 개선 기법으로 채택하지 않는다.
- Test PR-AUC는 004보다 높았지만 공통 임계값 Recall과 FCR은 모두 낮아졌다. 내부 Champion 005는 변경하지 않는다.
