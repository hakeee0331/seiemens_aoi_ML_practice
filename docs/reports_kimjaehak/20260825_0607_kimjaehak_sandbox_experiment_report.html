한 문장 결론

현재 champion 후보는 “inspection type별 XGBoost 5개 + Expanding 재학습”이며, 비용 정책은 모델과 분리해 직전 구간에서 갱신하는 구조가 적절합니다.

다만 실제 FP·FN 비용이 정해지지 않았고, 3개 후반 window를 이미 반복 분석했으므로 아직 최종 운영 모델이라고 부를 수 없습니다. 다음 단계는 정책 하나를 사전에 고정한 뒤 새로운 미래 데이터로 확인하는 것입니다.

Recommended system direction

어느 방향으로 모델을 만들어야 하나

지금까지의 결과는 “한 번 학습한 모델 + 고정 threshold”보다 모델 적응과 의사결정을 분리한 구조를 지지합니다.

남겨야 할 것

  • 검사유형별 모델 5개: mapping에 맞는 서로 다른 피처 공간과 점수 스케일을 인정합니다.
  • Expanding 재학습: 최근 데이터를 누적해 혼합 drift에 적응합니다.
  • 비용과 모델의 분리: PR-AUC로 모델을 선택한 후 별도 threshold 계층에서 비용을 반영합니다.
  • 희소 type fallback: 양성·음성이 부족하면 과도한 자동화를 피하고 수동 재검사를 유지합니다.
  • 시간 단위 모니터링: type별 PR-AUC, 양성률, score 분포, FN, 비용을 함께 봅니다.

현재는 버릴 것

  • 직전 Slip 1% point threshold: 다음 기간에 1%가 전이되지 않았습니다.
  • 모든 type 동일 리샘플링: 효과가 type과 시간에 따라 달랐습니다.
  • Type 2 1:4 undersampling 고정 적용: 시간 Fold 승률이 51.7%였습니다.
  • 공격적 전역 피처 축소: 약한 피처 조합 손실과 FN 증가 위험이 확인됐습니다.
  • Platt calibration 일괄 채택: 비용 신호는 있었지만 Brier와 기간 안정성이 일관되지 않았습니다.
운영 관점의 핵심: 1:100 비용 최적 정책은 Recall 79.43%로 좋아졌지만 실제 불량 530건을 놓쳤습니다. 비용 최소화와 안전 제약은 같은 목표가 아닙니다. 현장이 허용하는 FN 상한이 있다면 비용식에 묻어두지 말고 별도의 하드 제약으로 둬야 합니다.
Remaining gaps

부족한 점과 필요한 후속 실험

현재 데이터에서 유망한 방향은 찾았지만, 정책 확정에 필요한 독립성·비용 정의·희소 표본 불확실성이 남아 있습니다.

  1. 실제 비용과 안전 제약을 먼저 정의. FP 1건과 FN 1건의 상대 비용 범위, 그리고 비용과 무관하게 허용할 수 있는 FN 또는 Slip Rate 상한을 현장과 합의해야 합니다.
  2. 정책 하나를 사전에 고정한 미래 검증. 예: Expanding + type별 raw empirical threshold + 희소 type fallback. 비용비율과 fallback 규칙을 결과를 보기 전에 고정하고 새로운 시간 구간에 한 번 적용해야 합니다.
  3. 시간 Fold 수 확대와 불확실성 표시. 현재 핵심 평가는 W08~W10 세 구간입니다. 기간별 비용·Recall의 신뢰구간이나 block bootstrap을 함께 보고 평균 한 값에 의존하지 않아야 합니다.
  4. 희소 type용 위험 제어. Type 4처럼 양성 또는 음성이 거의 없는 구간은 점추정 threshold 대신 upper confidence bound, conformal risk control, 또는 전량 재검사 fallback을 비교해야 합니다.
  5. Type 2 가설을 새 Fold에서 분리 검증. 1:4 undersampling은 고정 적용하지 않습니다. 대신 no-meta가 shortcut·drift 신호를 제거하는지 진단하고, undersampling과 섞지 않은 상태로 미래 Fold에서 확인합니다.
  6. 재학습 주기와 데이터 보존 범위 결정. Expanding이 Rolling-6보다 좋았지만 오래된 데이터가 언제 독이 되는지는 아직 모릅니다. 월별/주별 재학습 주기와 최대 학습 기간을 별도 비교해야 합니다.
  7. 라벨 원인 데이터를 확보. 작업자 ID, AOI 프로그램·공정 변경 시점, 재검수 ground truth가 있어야 라벨 기준 변화와 실제 불량 증가를 구분할 수 있습니다.

가장 가치 있는 다음 실험

“Frozen cost policy future validation”이 우선입니다. Expanding 모델과 하나의 비용 정책을 완전히 고정하고, 아직 보지 않은 다음 기간에서 비용·FN·FCR을 평가합니다.
