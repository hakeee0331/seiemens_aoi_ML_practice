# 데이터 설명 Example

이 문서는 익명 데이터의 구조와 취급 규칙을 기록하는 형식의 **example**이다. 실제 데이터를 확인한 뒤 이 파일을 참고해 별도의 실제 데이터 문서를 작성한다.

## 위치

- 원본 데이터: `data/raw/`
- 원본 파일은 수정하거나 덮어쓰지 않는다.
- 전처리는 기본적으로 노트북 실행 시 수행한다.
- 실제 데이터 파일은 Git에 커밋하지 않는다.

## Example 스키마

| 컬럼 | 데이터 타입 | 역할 | 결측값 | 설명 |
|---|---|---|---:|---|
| `X001` | `float` | 입력 | 확인 예정 | 익명 연속형 변수 example |
| `X002` | `int` | 입력 | 확인 예정 | 익명 범주형 변수 example |
| `Y001` | `int` | 타깃 | 확인 예정 | 예측 대상 example |

## 실제 데이터 확인 후 기록할 항목

- 파일명과 파일 형식
- 행과 열의 개수
- 타깃 컬럼
- 각 컬럼의 데이터 타입과 역할
- 결측값 유무
- 값의 범위 또는 범주 수
- 데이터 분할 시 주의사항
- 프로젝트에서 합의한 전처리 규칙

실제 데이터 행이나 고유값은 필요한 경우에만 최소한으로 기록한다.
