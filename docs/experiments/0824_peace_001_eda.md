`notebooks/0824_peace_001_eda.ipynb`

완료

## 목적

Siemens AOI 수동검사 데이터의 구조와 품질을 확인하고, 실제 불량을 보호하면서 false call을 줄이는 모델을 설계하기 위한 기초 인사이트를 정리한다.

## 이전 실험 대비 주요 변경사항

- Example의 합성 데이터 대신 440,274행의 Siemens AOI 익명 데이터를 Polars LazyFrame으로 분석했다.
- 클래스 불균형, 검사 유형별 불량률, 일별 분포 변화, 특성 품질과 누수 후보를 점검했다.
- `mapping.json`을 사용해 검사 유형별 유효 특성을 구분했다.
- 시간 순서와 동일 timestamp를 보존하는 70%/15%/15% 학습·검증·테스트 분할을 제안했다.

## 평가 방법

본 실험은 모델 학습 전 EDA다. 다음 기준으로 데이터의 모델링 가능성과 검증 위험을 평가했다.

- 행·열 수, 결측값, NaN, 타임스탬프 범위
- `class` 및 `inspection_type` 분포
- 일별 실제 불량률과 급격한 변화 구간
- 검사 유형별 특성 분산·고유값·`class`와의 Pearson 상관계수
- 시간순 분할의 구간별 실제 불량률

## 주요 결과

| 항목 | 결과 |
|---|---:|
| 전체 크기 | 440,274행 × 78열 |
| Null / NaN | 0 / 0 |
| false call (`class=0`) | 435,652건, 98.95% |
| 실제 불량 (`class=1`) | 4,622건, 1.05% |
| 검사 유형별 불량률 | 0.328%~2.736% |
| Train 불량률 | 0.630% |
| Validation 불량률 | 0.806% |
| Test 불량률 | 3.256% |
| 전체 상수 특성 | 6개 |

- Test 구간의 불량률은 Train의 약 5.2배였고, 전체 실제 불량의 약 46.5%가 마지막 15% 구간에 포함됐다.
- `inspection_type=1`의 불량률이 2.736%로 가장 높았고, 유형 1에서 `inspection_feat48`과 `inspection_feat24`가 비교적 큰 선형 신호를 보였다.
- 시간 흐름에 따라 불량률이 크게 변하므로 랜덤 분할은 미래 정보 누수와 성능 과대평가를 일으킬 수 있다.

## 결론 및 다음 단계

- 정확도 대신 실제 불량 Recall, PR-AUC, Precision, false-call reduction rate를 평가한다.
- 시간순 검증에서 통합 모델과 검사 유형별 모델을 비교한다.
- 운영 임계값은 최소 실제 불량 Recall을 먼저 정한 후 수동검사 절감량을 최대화하도록 선택한다.
- 익명 메타 특성이 예측 시점에 사용 가능한 정보인지 확인해 데이터 누수를 방지한다.
