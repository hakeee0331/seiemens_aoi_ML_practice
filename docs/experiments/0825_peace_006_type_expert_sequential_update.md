## 목적

시간 배치가 도착할 때 기존 XGBoost에 트리를 이어 붙이는 순차 업데이트가 미래 구간과 최종 Test 성능에 미치는 영향을 확인한다.

## 주요 변경사항

- 기존 `0825_peace_004_type_expert_walk_forward`는 수정하지 않았다.
- 각 타입은 0~30%에서 200개 트리를 최초 학습했다.
- 30~40%, 40~50%, 50~60%, 60~70% 배치마다 50개 트리를 추가해 최종 400개 트리로 만들었다.
- 전처리 열 구성을 유지하기 위해 타입별 전처리기는 최초 0~30%에서만 fit하고 이후 update와 추론에 고정했다.
- `xgb_model`로 직전 Booster를 전달했으며 각 단계에서 누적 트리 수를 검증했다.
- 피처, 최종 트리 수, 클래스·시간 가중치 미적용 조건은 Fold 앙상블 실험과 동일하다.

## 결론 및 다음 단계

- 순차 업데이트의 Test PR-AUC는 0.277874로 Fold 앙상블의 0.382545보다 낮았다.
- 공통 임계값은 Recall이 더 높고, 타입별 임계값은 False Call Reduction이 더 높았다.
- 미래 Fold 공통 임계값의 최저 Recall은 93.42%로 목표 99%를 안정적으로 유지하지 못했다.
- 타입당 최종 모델 하나만 필요해 Fold 앙상블보다 추론 비용이 작지만, 이번 설정에서는 순위 품질과 시간 안정성이 낮았다.
