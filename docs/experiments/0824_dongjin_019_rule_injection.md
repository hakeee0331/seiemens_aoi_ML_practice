# 0824_dongjin_019_rule_injection

## 연결된 노트북
`notebooks/0824_dongjin_019_rule_injection.ipynb`

## 상태
완료

## 목적
이전 RuleFit 분석에서 얻어낸 "9개의 강력한 IF-THEN 명시적 룰"을 1과 0의 Boolean 피처(파생 변수)로 변환하여 기존 데이터셋에 주입(Inject)했습니다. 그리고 ADASYN 기반의 현 챔피언 모델과 동일한 조건으로 재학습하여, '전문가 지식'이 모델 성능에 어떤 영향을 미치는지 확인했습니다.

## 분석 결과 (Test Set 비교)

| 지표 | XGBoost + ADASYN (기존 챔피언) | XGBoost + ADASYN + **Rule Injection** | 변화 |
| :--- | :--- | :--- | :--- |
| **정밀도 (Precision)** | 44.58% | **48.51%** | **🔼 +3.93%p (대폭 상승)** |
| **재현율 (Recall)** | 49.26% | 47.08% | 🔽 -2.18%p |
| **오탐지 (False Positives)** | 1,377건 | **1,124건** | **🟢 253건 감소!** |
| **정탐지 (True Positives)** | 1,108건 | 1,059건 | 🔴 49건 감소 |
| **PR-AUC** | 0.4564 | 0.4489 | 🔽 -0.0075 |
| **정상 판독율 (Specificity)** | 98.19% | **98.52%** | 🔼 상승 |

### 💡 인사이트 및 결론
1. **오탐지(가짜 불량)의 획기적 감소**: RuleFit이 찾아낸 '확실한 불량 조건'을 변수로 직접 쥐여준 결과, 모델의 판단 기준이 훨씬 엄격하고 정교해졌습니다. 무려 253건의 오탐지(FP)를 추가로 걸러내는 데 성공했습니다.
2. **정밀도(Precision) 급상승**: 현장에서 알람이 울렸을 때 "진짜 불량일 확률(Precision)"이 44.5%에서 **48.5%**로 껑충 뛰었습니다. 거의 2번 울리면 1번은 무조건 진짜 불량이라는 뜻으로, 작업자의 검사 피로도(Fatigue)를 획기적으로 낮출 수 있는 매우 현장 친화적인 스코어입니다.
3. **Trade-off 발생**: 엄격해진 룰 덕분에 미세한 불량 49건(TP 감소)을 놓치게 되면서 Recall과 PR-AUC는 미세하게 하락했습니다. 하지만 제조 현장(AOI)에서는 "정밀도 4% 상승 / 오탐 250건 감소"가 주는 비용 절감 효과가 훨씬 더 클 수 있습니다.
4. **최종 제안**: '불량 유출을 단 1건이라도 더 막는 것'이 목표라면 기존의 **ADASYN 단독 모델**을, '오탐지로 인한 검사 인력의 피로도와 인건비를 줄이는 것'이 목표라면 이번 **Rule Injection 모델**을 선택하여 하이브리드로 운영하는 것이 최적입니다.
