## 목적

`0825_peace_004_type_expert_walk_forward`의 시간 분할, 타입별 유효 피처, XGBoost 파라미터, 임계값 선택 규칙은 그대로 유지하고, 각 타입의 현재 Train 데이터에서 계산한 `raw_ratio = 음성 수 / 양성 수`를 `sqrt(raw_ratio)`로 약화해 Fold별·최종 학습에 적용했을 때 미래 안정성과 최종 Test 성능이 어떻게 바뀌는지 확인한다.

## 주요 변경사항

- `mapping.json` 기반 타입별 유효 피처와 XGBoost 전문가 모델 5개 구성은 유지했다.
- 시간 가중치, 리샘플링, Fold 앙상블은 적용하지 않았다.
- 각 Fold와 최종 0~70% 학습에서 타입별 Train 데이터만 사용해 `raw_ratio`를 계산하고, 실제 XGBoost에는 `scale_pos_weight = sqrt(raw_ratio)`를 적용했다.
- Calibration Recall 99% 이상을 만족하는 공통·타입별 임계값 선택 규칙은 `0825_peace_004_type_expert_walk_forward`와 동일하게 유지했다.
- Walk-forward 이후 0~70% Train, 70~80% Validation, 80~100% Test 최종 평가도 동일하게 수행했다.
- 실행 로그는 `docs/peace/0825_peace_009_type_expert_sqrt_class_weight.log`에 저장했다.

## 결론 및 다음 단계

- `sqrt` 약화 덕분에 전체 class weight(`0825_peace_007`)보다 가중치 세기가 크게 줄었고, 실제 적용 범위도 Fold 기준 `7.77~29.71`, 최종 학습 기준 `8.13~24.04`로 내려왔다.
- 그 결과 고정 0.5 Test 성능은 PR-AUC 0.3785, Recall 49.0%, FCR 97.4%로 Baseline(`0825_peace_004`)보다 score 민감도는 높아졌지만, 전체 class weight 실험보다는 덜 공격적인 분포로 돌아왔다.
- 공통 임계값 전략은 Walk-forward 평균 Recall 98.9%, 최저 Recall 96.7%로 전체 class weight 실험보다 약간 안정적이었고, 최종 Validation FCR도 15.96%에서 29.71%로 개선됐다.
- 타입별 임계값 전략도 Validation FCR이 43.44%에서 47.87%, Test FCR이 32.1%에서 35.1%로 회복됐지만, 미래 Recall 99% 달성 Fold는 여전히 0개였다.
- 다만 Test 기준으로는 공통 임계값 FCR 21.1%, 타입별 임계값 FCR 35.1%라서 `0825_peace_004`의 60.9% / 46.7%보다 아직 크게 낮다. Recall 99% 제약을 만족시키기 위해 threshold가 여전히 과도하게 낮게 선택된다.
- 따라서 `sqrt` 약화는 전체 class weight의 과민반응을 줄이는 방향으로는 유효했지만, 단독으로는 운영용 threshold 안정성을 충분히 회복하지 못했다.
- `010` 결합 실험에서 Test PR-AUC는 0.3847로 추가 상승했지만 공통 임계값 FCR은 19.1%로 더 낮아져, 시간 가중치만 사용한 `008`이 운영 균형 측면에서 더 낫다.
