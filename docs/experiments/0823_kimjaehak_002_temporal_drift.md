# 0823_kimjaehak_002_temporal_drift

## 연결된 노트북

`notebooks/0823_kimjaehak_002_temporal_drift.ipynb`

## 상태

완료

## 목적

EDA 001에서 확인한 132일 시계열의 물량, true-defect 비율, 검사유형 구성, 검사 피처 분포 변화를 정량화하고 동일 timestamp 그룹을 보존하는 시간순 모델 평가 분할의 기준을 정한다.

## 이전 실험 대비 주요 변경사항

- 일별·주별 물량과 true-defect 비율을 시각화했다.
- 주별 및 시간순 분할별 `inspection_type` 구성비 변화를 확인했다.
- 동일 timestamp 그룹을 쪼개지 않고 누적 행 수가 60%, 80%에 가장 가까운 그룹 끝을 기준으로 train/validation/test를 분할했다.
- `mapping.json`의 검사유형별 유효·비상수 피처에 대해 train을 기준 분포, test를 비교 분포로 하는 PSI를 직접 구현했다. SciPy 등 추가 패키지는 사용하지 않았다.
- PSI는 train 고유값이 10개 이하이면 인접 고유값 중점, 그보다 많으면 train 10분위 경계를 사용하고, 탐색적 기준 `<0.10`, `0.10~0.25`, `>=0.25`로 drift 수준을 집계했다.

## 평가 방법과 주요 결과

- Python 3.12.13과 `requirements.txt` 환경에서 노트북의 12개 코드 셀을 위에서 아래로 전체 실행했다.
- 440,274행, 고유 timestamp 39,742개를 시간순으로 분할했다. train은 264,343행(60.0406%, 26,063개 그룹), validation은 87,879행(19.9601%, 6,586개 그룹), test는 88,052행(19.9994%, 7,093개 그룹)이며 분할 경계를 가로지르는 timestamp 그룹은 0개다.
- train의 마지막 시각은 `1970-09-28 05:10:37+00:00`, validation의 시작 시각은 `1970-09-28 05:11:13+00:00`이다. validation의 마지막 시각은 `1970-10-13 16:54:14+00:00`, test의 시작 시각은 `1970-10-13 16:54:52+00:00`이다.
- true-defect 비율은 train 0.7191%, validation 0.4506%, test 2.6405%였다. test 비율은 train의 약 3.67배로, 후기 구간에서 라벨 분포가 크게 달라졌다.
- 101개 관측일의 일별 표본 수는 12~23,046개, 일별 true-defect 비율은 0~14.6868%였다. 20개 주의 주별 표본 수는 1,208~51,992개, 주별 true-defect 비율은 0.0832~4.2572%였다.
- train 대비 test의 검사유형 구성비 변화는 type 0 +2.4016%p, type 1 +1.0866%p, type 2 -9.3671%p, type 3 +6.3645%p, type 4 -0.4855%p였다. 가장 큰 절대 변화는 type 2에서 나타났다.
- test의 검사유형별 true-defect 비율은 type 0 1.0005%, type 1 6.2667%, type 2 3.5584%, type 3 1.7516%, type 4 1.7857%였다. 모든 유형에서 train보다 높아 전체 라벨 변화는 검사유형 구성비 변화만으로 설명되지 않는다.
- 유형별 매핑 유효·비상수 피처는 type 0 37개, type 1 24개, type 2 20개, type 3 19개, type 4 13개이며 113개 모두 train에서 PSI 계산이 가능했다.

- 최대 PSI는 type 4의 `inspection_feat7`에서 4.2469였다. 다만 type 4의 test 표본은 728행으로 유형 중 가장 적으므로 표본 크기와 binning 민감성을 함께 고려해야 한다.
- PSI `>=0.25` 피처는 type 1~4에서 모두 발견됐고 type 4는 평가한 13개 중 11개가 해당했다. type 0은 큰 drift 피처가 없었다.

## 결론과 다음 단계

- 모델 베이스라인은 동일 timestamp 그룹을 보존한 시간순 60/20/20 분할을 사용하고, 전처리 통계와 피처 제거 기준을 train에만 fit한다.
- 전체 성능뿐 아니라 split·inspection_type별 PR-AUC, true-defect recall, false-call reduction을 함께 보고해 후기 구간과 특정 검사유형의 성능 저하를 확인한다.
- PSI가 큰 피처는 주별 PSI 또는 rolling 통계로 변화 시점을 좁히고, 메타 피처·검사유형 구성 변화 및 알려지지 않은 AOI 설정 변경 가능성과 함께 검토한다.
- type 4처럼 후기 표본이 작은 유형은 PSI 순위만으로 피처를 제거하지 않고 bootstrap 신뢰구간이나 더 긴 모니터링 창을 검토한다.
- PSI는 단변량 drift 기술통계이므로 시간 구간 판별 모델이나 실제 예측 성능 변화로 다변량 drift를 보완한다.
