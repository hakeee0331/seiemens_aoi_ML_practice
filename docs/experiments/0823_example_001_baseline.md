# 0823_example_001_baseline

> 이 문서는 실험 설명의 **example**이다. 실제 실험 문서는 이 구조를 참고하되 가상 내용과 결과를 그대로 복사하지 않는다.

## 연결된 노트북

`notebooks/0823_example_001_baseline.ipynb`

## 상태

Example

## 목적

합성 익명 데이터를 사용하여 노트북 및 실험 문서 작성 형식을 보여준다.

## 주요 변경사항

- 합성 데이터의 입력 컬럼을 `X001`부터 `X004`까지 구성했다.
- 학습·검증 데이터를 8:2로 분리했다.
- 결측값 대체, 표준화, Logistic Regression을 하나의 파이프라인으로 구성했다.
- 랜덤 시드로 `42`를 사용했다.

## 평가 방법

- 검증 데이터에서 Accuracy와 F1 score를 계산한다.
- 실제 프로젝트의 평가 지표는 팀원과 회의 후 결정한다.

## 주요 결과

이 example의 수치는 합성 데이터와 실행 환경에 따른 예시다. 노트북을 전체 실행한 뒤 마지막 출력에서 확인한다.

## 결론 및 다음 단계

- 이 실험은 모델 성능 판단이 아니라 작성 형식 확인을 위한 example이다.
- 실제 데이터 구조가 결정되면 `docs/data_example.md`를 참고해 실제 데이터 문서를 작성한다.
- 실제 실험은 example 파일을 복사한 뒤 올바른 날짜, 작성자, 번호와 설명으로 이름을 변경한다.
