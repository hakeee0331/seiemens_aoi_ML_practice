## 목적

EDA 001에서 확인한 검사유형별 `mapping.json`, 상수열, 매핑 제외 피처의 채움 패턴을 심층 분석하여 모델 입력에 사용할 피처의 안전한 판정 규칙을 정한다.

## 이전 실험 대비 주요 변경사항

- 70개 검사 피처의 매핑 범위를 전수 검증하고 어떤 검사유형에도 매핑되지 않은 피처를 구분했다.
- 검사유형별 유효 피처를 상수, 준상수, 저분산, 잠정 후보로 상호 배타적으로 분류했다.
- 매핑 제외 `(inspection_type, inspection_feat)` 조합을 항상 0, 0이 아닌 상수, 가변값으로 분류했다.
- 매핑 제외 셀의 값이 해당 피처의 유효값 집합과 정확히 겹치는지 검사해 값 기반 마스킹의 위험을 측정했다.

## 평가 방법과 주요 결과

- Python 3.12.13과 `requirements.txt` 환경에서 노트북의 10개 코드 셀을 위에서 아래로 전체 실행했다.
- CSV의 검사유형 5개와 매핑 키 5개가 일치하고, 매핑 내부 중복이나 CSV에 없는 피처 참조는 없다.
- 70개 검사 피처 중 65개가 적어도 한 검사유형에 매핑되고 5개는 어떤 유형에도 매핑되지 않는다. 17개 피처는 모든 검사유형에 공통으로 매핑된다.
- 피처별 매핑 범위는 0개 유형 5개, 2개 유형 1개, 3개 유형 28개, 4개 유형 19개, 5개 유형 17개다.
- 유효 피처 분류 기준은 `상수=nunique<=1`, `준상수=상수가 아니면서 최빈값 비율>=99%`, `저분산=앞의 두 범주가 아니면서 모집단 분산<=1e-4`로 정했다.

## 결론과 다음 단계

- `mapping.json`을 피처 유효성의 유일한 기준으로 사용하고, 어떤 유형에도 매핑되지 않은 5개 피처는 전역 제외 대상으로 관리한다.
- 우선 권장안은 검사유형별로 데이터를 분기하여 해당 유형의 매핑 피처만 선택하는 것이다. 통합 모델을 사용한다면 구조적 결측 마스크와 `inspection_type`을 함께 사용하되 유형별로 다른 물리적 의미를 주의한다.
- 상수·준상수·저분산 필터는 시간순·timestamp 그룹 보존 분할 후 train 구간에만 적합하고 validation/test에는 확정 목록을 그대로 적용한다.
- 검사유형별 선택 피처 수와 매핑 제외 셀의 비0 비율을 운영 중 스키마·분포 변화 지표로 모니터링한다.
- 후속 모델링에서는 유형별 모델과 `inspection_type`을 포함한 통합 모델을 동일 분할과 운영 지표로 비교한다.
