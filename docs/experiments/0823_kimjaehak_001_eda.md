`notebooks/0823_kimjaehak_001_eda.ipynb`

## 상태

완료

## 목적

Siemens PCB AOI 원본 데이터의 전체 구조, 타깃 불균형, 검사유형별 피처 구성, 데이터 품질, 시간 및 그룹 구조를 확인하여 이후 전처리와 모델링의 기준을 정한다.

## 이전 실험 대비 주요 변경사항

- 실제 `data/raw/dataset.csv`와 `data/raw/mapping.json`을 처음으로 분석한다.
- 데이터 설명 논문 `docs/1-s2.0-S2352340924000830-main.pdf`의 데이터 생성 과정과 한계를 분석 기준으로 사용한다.
- 실제 데이터 행이나 불필요한 고유값 대신 재현 가능한 집계 결과를 출력한다.

## 평가 방법과 주요 결과

- Python 3.12.13과 `requirements.txt` 환경에서 노트북의 14개 코드 셀을 위에서 아래로 전체 실행했다.
- 스키마는 440,274행 × 공식 컬럼 77개이며, CSV에는 별도의 헤더 없는 행 식별자 1개가 추가로 있다. 공식 컬럼의 자료형은 `float64` 70개, `int64` 6개, 문자열 1개다.
- 결측 셀과 수치형 무한값은 모두 0건이고 행 식별자는 중복 없이 440,274개다.
- `class=1` true defect는 4,622건(1.0498%), `class=0` false call은 435,652건(98.9502%)이다.
- 검사유형별 true defect 비율은 type 0이 0.3277%, type 1이 2.7361%, type 2가 1.0501%, type 3이 0.8431%, type 4가 1.8188%로 차이가 크다.
- `mapping.json`의 5개 검사유형과 CSV의 검사유형이 일치하며, 유형별 유효 검사 피처는 각각 44, 52, 65, 65, 21개다. 모든 유형에 공통으로 유효한 검사 피처는 17개다.
- 매핑에서 제외된 피처의 0 비율은 type별로 61.5385%, 44.4452%, 0%, 0%, 72.4713%였다. 논문에 기술된 기본값 0만으로 피처의 유효 여부를 판정할 수 없으며 `mapping.json`을 명시적으로 적용해야 한다.
- 유형별 유효 피처 중 상수열은 각각 7, 28, 45, 46, 8개다. 전체 데이터에서도 검사 피처 6개가 상수다.
- `record_id`를 제외한 공식 컬럼 기준 완전 중복 초과 행은 8,752건(1.99%)이며, 중복 그룹에 포함된 전체 행은 13,002건이다.
- timestamp는 1970년으로 익명화된 132일 범위이며, 실제 관측일은 101일이다. 고유 timestamp 그룹은 39,742개이고, 여러 검사유형을 포함하는 그룹은 27,322개, 서로 다른 라벨을 포함하는 그룹은 715개다.
- 70개 검사 피처는 모두 [0, 1] 범위 안에 있고 범위 이탈값은 없다.

## 결론과 다음 단계

- 모델링은 검사유형별로 분리하거나 검사유형별 매핑을 적용하는 파이프라인으로 구성해야 한다.
- 동일 timestamp 그룹이 여러 데이터 분할에 섞이지 않도록 하며, 잠재적 drift를 반영해 무작위 분할보다 시간순 Train/Validation/Test 분할을 우선한다.
- Accuracy보다 PR-AUC, true-defect recall, false-call reduction처럼 불균형과 운영 비용을 반영한 지표를 사용한다.
- 후속 EDA 후보는 시간 구간별 drift, 유형별 상수·저분산·무효 피처 패턴, 완전 중복과 timestamp 그룹의 발생 구조다. 각각 별도 노트북으로 분리할 수 있다.
