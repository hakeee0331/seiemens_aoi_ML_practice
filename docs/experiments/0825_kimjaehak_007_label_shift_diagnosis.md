# 0825_kimjaehak_007_label_shift_diagnosis

## 연결된 노트북

`notebooks/0825_kimjaehak_007_label_shift_diagnosis.ipynb`

## 상태

완료

## 목적

시간 후반부의 `class=1` 증가가 검사유형 구성 변화, 측정 피처 분포 변화, 동일 입력에 대한 라벨 판정 기준 변화 중 무엇과 더 관련되는지 진단한다.

`0824_kimjaehak_006_type_conditioned_baseline`을 고정 기준으로 사용하여 `0825_lsw_005_drift_label_robust`의 핵심 전제인 시간에 따른 라벨 기준 변화를 독립적으로 검증한다. 관찰 데이터만으로 작업자 변경이나 실제 불량 원인을 확정하지 않는다.

## 이전 실험 대비 주요 변경사항

- 원본 440,274행은 실제 반복 빈도와 동일 입력 signature의 라벨 이력 분석에 사용했다.
- `kimjaehak_006`과 동일하게 `record_id`, `timestamp`를 제외하고 중복 제거한 391,992행은 시간 구간과 모델 비교에 사용했다.
- 동일 timestamp 그룹을 보존한 60/20/20 split에 더해 누적 행 수 기준 10개 시간 윈도우를 구성했다.
- 전체 라벨률 변화를 inspection type 구성 효과와 유형 내부 라벨률 효과로 분해했다.
- Train의 `inspection_type`과 `meta_feat`만 학습한 보조 모델로 범주 구성만으로 기대되는 미래 라벨률을 계산했다.
- 동일 signature의 최초 라벨 등장 순서와 원본 반복행의 최초·최종 라벨 방향을 별도로 집계했다.
- mapping 유효 피처의 Train 대비 미래 윈도우 PSI를 계산했다.
- `kimjaehak_006`과 같은 type-conditioned XGBoost 5개를 Train에서 재학습하고 미래 윈도우에 고정 적용했다.

## 평가 방법과 주요 결과

### 라벨 비율과 구성 효과

- 첫 윈도우 W01의 `class=1` 비율은 0.186177%, 마지막 W10은 3.336820%로 3.150643%p 상승했다.
- W10과 W01의 차이를 분해하면 inspection type 구성 효과는 -0.270803%p, 유형 내부 라벨률 효과는 +3.421446%p였다.
- 검사유형 구성 변화는 오히려 전체 상승을 0.270803%p 낮추는 방향이었다. 후반부 상승은 유형 내부 변화가 지배했다.
- Train의 inspection type·meta 구성만 반영한 보조 모델의 W10 기대 라벨률은 2.368510%였고 실제는 3.336820%로 0.968310%p 높았다.

### 동일 입력 signature 라벨 전환

- 라벨 충돌 signature는 70개 그룹이다.
- 원본 반복 빈도를 보존하면 관련 행은 14,037행이고, `kimjaehak_006` 중복 제거 표현에서는 signature별 라벨당 한 행만 남아 140행이다.
- 각 라벨의 최초 등장 시점을 비교하면 `0→1` 57개, `1→0` 13개였다. 양측 exact binomial p-value는 `1.029e-07`이다.
- 원본의 최초 timestamp와 최종 timestamp 라벨 집합을 비교하면 명확한 `0→1` 33개, `1→0` 12개, 동일 또는 mixed 23개, 모호 2개였다.
- 따라서 후반부에 동일 입력이 `1`로 처음 판정되는 방향의 비대칭은 강하지만, 모든 그룹이 단방향으로 바뀐 것은 아니다.

### 피처 drift

- type별 mapping 유효·Train 비상수 피처 113개를 미래 4개 윈도우와 비교하여 452개 PSI를 계산했다.
- PSI 0.25 이상은 162개였다.
- type 4는 52개 비교 중 47개가 0.25 이상이었고, W09의 `inspection_feat7` PSI가 6.536029로 가장 컸다.
- type 3도 W10에서 19개 중 16개가 0.25 이상이었다.
- 따라서 `lsw_005`의 해석처럼 입력 `X` 분포가 변하지 않았다고 단정할 수 없다.

### 고정 `kimjaehak_006` baseline의 미래 예측

- `kimjaehak_006`의 Test PR-AUC 0.315411과 threshold 0.5 Recall 0.316141을 정확히 재현했다.
- 미래 첫 윈도우 W07에서 마지막 W10까지 실제 라벨률은 3.244936%p 상승했고, 평균 baseline 점수는 3.104136%p 상승했다.
- 모델 점수 변화는 라벨률 변화의 95.66%를 따라갔다.
- W10의 실제 라벨률은 3.336820%, 평균 모델 점수는 3.380174%로 차이는 -0.043354%p였다.
- 이는 후반부 라벨 증가의 상당 부분이 `kimjaehak_006` 모델이 포착할 수 있는 입력 신호 변화와 동반됐음을 뜻한다.

## `lsw_005`와의 비교

[`0825_lsw_005_drift_label_robust`](0825_lsw_005_drift_label_robust.md)는 후기로 갈수록 라벨 판정 기준이 엄격해졌다는 전제에서 다음 두 대응을 시험했다.

1. 최근 Train 데이터에 더 큰 가중치를 주는 recency weighting
2. 동일 입력의 충돌 라벨을 가장 최근 라벨로 통일하는 보정

`lsw_005`의 두 대응은 다음 의미에서 `lsw_004`의 검사유형별 최적 조합을 이기지 못했다.

- **Recency weighting**은 type 0·1 일부 비용 조건에서 baseline보다 나았지만, `lsw_004`가 선택한 type별 최적 기법보다 총비용이 높았다.
- **최근 라벨 보정**은 type 2에서 충돌 행 삭제보다 손해가 작았지만 아무것도 하지 않은 baseline보다 나빴고, type 0에서는 TN이 크게 감소해 총비용이 악화됐다.
- 따라서 `lsw_005`는 두 방법을 새로운 최적 기법으로 채택하지 않았고, `lsw_004`의 type별 최적 조합을 그대로 유지했다.

`kimjaehak_007`은 이 두 방법을 다시 학습해 성능을 재비교한 실험이 아니다. 이미 실패가 확인된 방법을 반복하는 대신, 실패의 출발점이었던 다음 질문을 진단했다.

1. 후반부 `class=1` 증가는 inspection type 구성 변화 때문인가?
2. 동일한 측정 입력에 대한 라벨이 실제로 `0→1` 방향으로 변했는가?
3. 입력 피처 `X`의 분포도 함께 변했는가?
4. 고정된 `kimjaehak_006` 모델의 불량 점수가 실제 라벨 증가를 따라가는가?

즉, `lsw_005`는 **“drift에 어떻게 대응할 것인가?”**를 시험했고, `kimjaehak_007`은 **“관측된 drift가 실제로 어떤 종류인가?”**를 분해했다.

| 비교 항목 | `lsw_005`의 전제 또는 결과 | `kimjaehak_007`의 검증 결과 | 함께 봤을 때의 해석 |
|---|---|---|---|
| 후반부 라벨 기준 변화 | 최근으로 갈수록 `0→1` 판정이 늘었다고 가정 | 동일 signature의 최초 라벨 등장 순서가 `0→1` 57개, `1→0` 13개였고 p-value는 `1.029e-07` | 라벨 기준이 엄격해졌다는 정황은 지지된다 |
| 검사유형 구성 영향 | 직접 분해하지 않음 | 구성 효과 -0.270803%p, 유형 내부 효과 +3.421446%p | 후반부 상승은 불량률이 높은 type이 많아진 것만으로 설명되지 않는다 |
| 최근 라벨로 통일 | type 2에서는 삭제보다 덜 나빴지만 baseline보다 나빴고, type 0에서는 크게 악화 | 원본 endpoint는 `0→1` 33개, `1→0` 12개 외에도 동일·mixed 23개와 모호 2개가 존재 | 모든 충돌 그룹의 최신 라벨을 정답으로 보는 규칙은 실제 전환 구조를 지나치게 단순화한다 |
| Recency weighting | 일부 유형만 개선됐고 기존 최적 기법을 이기지 못함 | 실제 라벨률 상승과 함께 고정 `kimjaehak_006` 모델 점수도 95.66%만큼 상승 | drift가 존재해도 일괄 시간감쇠가 올바른 대응이라는 뜻은 아니다 |
| 입력 `X` 분포 | 재학습 트리거 설명에서 `X` 분포는 변하지 않는 순수 concept drift로 해석 | 미래 PSI 452개 중 162개가 0.25 이상이고 type 4·type 3 변화가 특히 큼 | `X`가 변하지 않았다는 해석은 수정해야 한다 |
| 최종 결론 | recency weighting과 최신 라벨 보정은 채택하지 않음 | 라벨 변화 정황과 피처 drift가 동시에 관찰됨 | `lsw_005`의 대응 기법 기각은 유지되지만, 문제의 원인은 순수 concept drift보다 혼합 drift로 보는 것이 타당하다 |

따라서 `kimjaehak_007`은 `lsw_005`를 전부 반박하거나 전부 확인하는 결과가 아니다. **`lsw_005`의 라벨 기준 변화 가설은 지지하지만, `X`는 변하지 않았다는 원인 해석은 수정한다.** 또한 `lsw_005`의 두 방법이 실패한 것은 drift가 없어서가 아니라, 여러 종류의 drift가 섞인 문제를 하나의 시간가중치나 최신 라벨 규칙으로 해결하려 했기 때문일 수 있다.

## 결론과 다음 단계

- 동일 signature의 최초 라벨 등장 순서가 `0→1`로 강하게 치우치고, inspection type 구성 변화로 설명되지 않는 유형 내부 라벨률 상승이 확인됐다. 따라서 `lsw_005`의 “후기로 갈수록 라벨 판정이 더 엄격해졌을 수 있다”는 가설은 정황상 지지된다.
- 반면 mapping 유효 피처에서 큰 PSI가 다수 발견됐고 고정 `kimjaehak_006` 모델 점수도 실제 라벨률 상승의 95.66%를 따라갔다. 따라서 현상을 순수한 `P(y|X)` 변화 또는 라벨 기준 변화 하나로만 설명하는 `lsw_005`의 해석은 지지되지 않는다.
- 현재 증거에 가장 부합하는 설명은 라벨·개념 변화 정황과 모델이 포착하는 피처 분포 변화가 함께 존재하는 혼합 drift다.
- 작업자 ID, AOI 프로그램 변경 이력, 재검수 ground truth가 없어 작업자 판정 변화와 실제 공정 불량 증가를 인과적으로 구분할 수 없다.
- 전체 기간 라벨을 진단에 사용했으므로 후속 drift 대응 모델은 별도 walk-forward 평가 프로토콜로 새 실험을 구성한다.

## 저장 모델

해당 없음. `kimjaehak_006` baseline을 재학습해 진단에 사용했지만 새로운 모델 후보를 생성하거나 저장하지 않았다.
